#  EXPLORADOR AMOLED // PYTHON DESKTOP

> *Um gerenciador e explorador de arquivos desktop desenvolvido em Python com interface moderna, tema escuro absoluto (AMOLED) e total liberdade de navegação.*

---

##  Visão Geral do Sistema

O **Explorador Amoled** nasceu da necessidade de um gerenciador de arquivos que fuja dos padrões engessados dos sistemas operacionais tradicionais. Projetado com foco total em estética minimalista de alto contraste (ideal para telas OLED/AMOLED) e performance, ele oferece ao usuário uma experiência fluida, sem frescuras e com controle total sobre o ambiente de arquivos local.

---

##  Tecnologias e Arquitetura

Este projeto foi construído utilizando conceitos modernos de desenvolvimento desktop em Python:

* **Linguagem:** Python 3.x
* **Interface Gráfica (GUI):** Customizada para alta performance visual.
* **Gerenciamento de Arquivos:** Manipulação nativa de diretórios, leitura de metadados e controle de rotas locais.
* **Distribuição:** Disponibilizado como executável (`.exe`) standalone para fácil portabilidade.

---

##  Funcionalidades Principais

* **Interface AMOLED (Dark Mode Absoluto):** Cores profundas projetadas para reduzir o cansaço visual e otimizar o consumo de energia em displays compatíveis.
* **Navegação Livre:** Acesso direto a pastas, diretórios e arquivos com respostas rápidas e sem bloqueios arbitrários.
* **Operações de Sistema:** Visualização de caminhos, hierarquia de diretórios e execução de arquivos diretamente pela interface.
* **Portabilidade Total:** Disponível na aba de releases para uso direto em sistemas Windows sem necessidade de configurações complexas de ambiente.
